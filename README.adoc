= Quiet.
:toc:

Quiet is a restrained interface color system for long-duration work.

The interface should become scenery.

Color is allowed to organize.  It is not allowed to shout.

== Status

Quiet is under development toward its first release.

The current canonical anchors are frozen pending external review,
reference-port work, and broader testing.

The existence of a candidate Quiet Core specification does not constitute a
Quiet 0.1 release.

== Variants

* Quiet Day
* Quiet Night

Both implement the same semantic core.  They are adaptations, not
mathematical inversions.

== Specification

The candidate human-readable specification is:

* link:spec/quiet-core.adoc[Quiet Core]

Machine-readable inputs are:

----
spec/quiet-core.json
spec/quiet-day.json
spec/quiet-night.json
----

== Reference implementation

The reference implementation is written in Go.

Run the complete local verification suite with:

----
make check
----

Build the command-line tool with:

----
make build
----

The resulting executable is:

----
bin/quiet
----

Validate the canonical palettes with:

----
bin/quiet check \
    spec/quiet-core.json \
    spec/quiet-day.json \
    spec/quiet-night.json
----

The expected result is:

----
Quiet Day: PASS (19/19)
Quiet Night: PASS (19/19)
----
