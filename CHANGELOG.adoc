= quiet changelog

Notable changes to quiet: the quiet-core specification, the canonical
palettes, the machine-readable contract, the reference implementation, and
the first-party ports.

A quiet version covers the whole repository.

Schema identifiers such as `quiet.core/v1` version serialized data formats
independently.  They are not quiet release numbers.

Before quiet 1.0, any release may change canonical anchors, derivations, or
contract constraints.  Such changes are always listed here.

The candidate quiet-core and its initial ports predate this changelog.

== 0.1.0 (2026-10-25)

The first quiet release.  quiet-core remains a candidate: its anchors are
not yet frozen.

=== quiet-core

* Added Wash, a derived role for regions that carry a chromatic family's
  meaning, such as diff lines and diagnostic lines.  Wash has a line tier
  and an emphasis tier.
* Added eight Field-grounded wash roles to the contract, such as
  `moss-wash` and `moss-wash-emphasis`.
* Extended the quiet-core contract from 19 to 47 contrast constraints.

=== Ports

* Moved diff, merge, search, and reference highlighting in the VS Code,
  Neovim, Vim, and Emacs ports onto the Wash roles.  Lines take line
  washes and keep their syntax colors; changed words are outlined in VS
  Code, and take Ink on an emphasis wash elsewhere.
* VS Code: added the diff and merge editors, gutter, overview ruler and
  minimap, peek views, error navigation, inlay hints, notifications,
  input validation, testing, and debugging colors.  Where VS Code is
  installed, tests check every color key against VS Code's own.
* Neovim: diagnostics and spelling keep Neovim's underlines, undercurls,
  and strikethroughs in quiet's colors instead of recoloring code; added
  the terminal palette, `Added`/`Changed`/`Removed`, and newer groups.
  Where Neovim is installed, tests load both schemes and check each
  group's cues against Neovim's defaults.
* Emacs: added diff, ediff, smerge, Flymake, Flyspell, ANSI color, tab
  bar, and Emacs 29 tree-sitter faces; diagnostics keep Emacs's wavy
  underlines and links their underline.  Where Emacs is installed, tests
  load both themes and check every face against Emacs's own.
* Noted the unrelated built-in `quiet` colorschemes in Vim and Neovim and
  VS Code's Quiet Light theme in the port READMEs.
* Removed the CDE port.  quiet no longer provides CDE palettes.
* Added the JetBrains port: a plugin with `quiet-day` and `quiet-night`
  interface themes built on JetBrains' Islands themes, and matching editor
  color schemes, also provided on their own for import.  Diff views use the
  Wash roles; the console uses quiet's terminal palette.  Where a JetBrains
  IDE is installed, tests check every key against the IDE's own themes and
  schemes, and check that every opaque interface color resolves to a quiet
  role.
* Added the Chrome port: `quiet-day` and `quiet-night` themes for Chrome's
  interface, following the Firefox mapping.  Tests validate each theme
  with Chrome's extension packer where Chrome is installed.
* Added the Firefox port: `quiet-day` and `quiet-night` themes for
  Firefox's interface.  Web pages keep following the system appearance.
* Added the delta port: `quiet-day` and `quiet-night` delta features.
  Changed lines use the Wash roles and keep syntax highlighting; changed
  words use Ink on the emphasis washes.  The port keeps delta's `+` and `-`
  markers, because the Moss and Rust washes nearly coincide under simulated
  deuteranopia.
* Added the tmTheme port for bat and Sublime Text.  Its syntax rules come
  from a shared TextMate scope policy that the VS Code port now also uses,
  so both highlight source identically.  The tmTheme adds diff scopes and
  forces selected text to Ink.
* Added the fzf port: `--color` options for `FZF_DEFAULT_OPTS_FILE`.
  Matches on the current line are Ink in bold, because Mineral on
  Selection falls below 4.5:1.

=== Naming

* The project, adaptations, and specification are named `quiet`,
  `quiet-day`, `quiet-night`, and `quiet-core`, in lowercase everywhere.
  Host theme pickers now show `quiet-day` and `quiet-night`.
* Generated files no longer contain spaces or capitals.  Existing
  installations must use the new names:
+
----
ports/cde/QuietDay.dp                          -> ports/cde/quiet-day.dp
ports/ghostty/Quiet Day                        -> ports/ghostty/quiet-day
ports/iterm2/Quiet.itermcolors                 -> ports/iterm2/quiet.itermcolors
ports/kitty/Quiet Day.conf                     -> ports/kitty/quiet-day.conf
ports/wezterm/Quiet Day.toml                   -> ports/wezterm/quiet-day.toml
ports/xcode/Quiet Day.xcworkspacecolortheme    -> ports/xcode/quiet-day.xcworkspacecolortheme
----
+
Night files follow the same pattern.
* The naming convention is recorded in `CONTRIBUTING.adoc`.

=== Reports

* Added `reports/`: quiet-core conformance, Wash derivation evidence, and
  color-vision deficiency screening, as Org sources with generated tables
  and exported PDFs.
* Added `quiet report`, which generates the report tables, and the
  `report-data` and `reports` make targets.
* Added color-vision deficiency simulation (Machado 2009, full severity) to
  the reference implementation.
* Screening finding: under simulated deuteranopia the Moss and Rust line
  washes nearly coincide, and under protanopia or deuteranopia some
  quiet-day chromatic anchors fall slightly below 4.5:1 on Field.  Neither
  is a conformance failure; both are recorded as evidence.

=== Exports

* The machine-readable export and the web CSS export carry the
  Field-grounded washes.

=== Project

* Added continuous integration: `make check`, regeneration of every
  generated port, and Terminal.app profile regeneration on macOS.
* Added committed-artifact drift tests for the tmux and CDE ports.
* The tmux port's mapping is now a declarative table of tmux options and
  quiet roles.  Generated overlays are unchanged.
* Added this changelog.
* Added a single release version, `internal/release.Version`.  Generated
  browser and IDE manifests take their version from it, and tests check that
  the VS Code and Emacs package versions and this changelog agree.
* The Emacs package header now names Chris Mecca with a contact address,
  matching `LICENSE`.
