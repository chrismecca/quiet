= quiet for Alacritty

quiet's Alacritty port provides `quiet-day` and `quiet-night` color
configurations.

Terminal colors come from quiet's generic terminal palette, as in quiet's
other terminal ports.

== Files

----
quiet-day.toml
quiet-night.toml
----

The files are generated from the canonical quiet palettes.

== Installation

Copy a file next to your Alacritty configuration and import it from
`alacritty.toml`:

----
[general]
import = ["quiet-night.toml"]
----

A path relative to the configuration file, or one starting with `~/`, also
works.

== Mapping

[cols="2,2"]
|===
| Alacritty color | quiet role

| `primary.foreground` / `primary.background`
| Ink / Field

| `primary.dim_foreground`
| Muted

| `cursor`, `vi_mode_cursor`
| Mineral, with Field text

| `selection`
| Ink on Selection

| `search.matches`
| Mineral wash, keeping each cell's color

| `search.focused_match`, `hints.start`
| Field on Mineral

| `hints.end`
| Ink on Selection

| `footer_bar` / `line_indicator`
| Ink / Muted on Structure

| `normal`, `bright`
| quiet's generic terminal palette
|===

Search matches keep each cell's own color.  The Mineral wash keeps Ink and
every chromatic terminal color at its contract minimum.

Alacritty computes dim colors from the normal colors, so the port sets
none.

== Testing

The test suite verifies that:

* the committed files match generator output;
* the terminal colors match quiet's generic terminal palette;
* Ink and every chromatic terminal color stay readable on search matches;
* the files set only colors.

== Generation

----
make alacritty
----
