= quiet for GNU Emacs

quiet provides two GNU Emacs Custom themes:

----
quiet-day
quiet-night
----

The themes map quiet semantic roles onto Emacs faces without imposing font,
weight, slant, box, or other typography policy.

The generated theme files are:

----
quiet-day-theme.el
quiet-night-theme.el
----

The package entry point is:

----
quiet-themes.el
----

== Requirements

The packaged quiet Emacs port targets GNU Emacs 29.1 or later.

== Install directly from Git

GNU Emacs can install quiet directly from its public Git repository with
`package-vc-install`.

Evaluate:

[source,elisp]
----
(package-vc-install
 '(quiet-themes
   :url "https://github.com/chrismecca/quiet.git"
   :lisp-dir "ports/emacs"
   :main-file "quiet-themes.el"))
----

The package is then managed by the normal Emacs package system.

== use-package

Current Emacs releases can also install the package through `use-package` and
`package-vc`:

[source,elisp]
----
(use-package quiet-themes
  :vc (:url "https://github.com/chrismecca/quiet.git"
       :lisp-dir "ports/emacs"
       :main-file "quiet-themes.el")
  :config
  (load-theme 'quiet-night t))
----

Without `:rev`, use-package installs the commit that last changed the
`Version` header of `quiet-themes.el`, which is quiet's latest release.
Add `:rev :newest` to follow `main` instead.

== Load a theme

Interactively:

----
M-x load-theme RET quiet-day RET
----

or:

----
M-x load-theme RET quiet-night RET
----

From Emacs Lisp:

[source,elisp]
----
(load-theme 'quiet-day t)
----

or:

[source,elisp]
----
(load-theme 'quiet-night t)
----

== Switch Day and Night

quiet-day and quiet-night are members of the same native Emacs theme family.

With exactly one quiet theme active:

----
M-x theme-choose-variant
----

switches to the other adaptation.

quiet does not implement a separate theme-switching command where the host
already provides the appropriate mechanism.

== Package archives

The package name is:

----
quiet-themes
----

Archive installation will use the ordinary package interface:

----
M-x package-install RET quiet-themes RET
----

once quiet is accepted into an Emacs package archive.

No `quiet-themes-pkg.el` is stored in this repository. Package archives
generate package metadata from `quiet-themes.el`.

The MELPA recipe is:

[source,elisp]
----
(quiet-themes :fetcher github
              :repo "chrismecca/quiet"
              :files ("ports/emacs/*.el"))
----

MELPA's existing `quiet` package is unrelated.

The package byte-compiles without warnings and passes `checkdoc`.
`package-lint` reports one error per theme file: the theme names,
`quiet-day` and `quiet-night`, do not start with the package prefix
`quiet-themes`.  Theme names are what users load, so they keep quiet's
names.

Some multi-theme packages, such as modus-themes, avoid the error by
defining themes through their own macro.  quiet keeps a plain `deftheme`
with an autoload cookie, so Emacs knows each theme's family before it is
loaded, as `theme-choose-variant` expects.

== Manual installation

For installations that do not use package management, add this directory to
`custom-theme-load-path`:

[source,elisp]
----
(add-to-list
 'custom-theme-load-path
 "/path/to/quiet/ports/emacs")
----

Then load either theme normally.

== Semantic mapping

quiet treats programming-language syntax as hierarchy rather than a collection
of unrelated token colors.

Ordinary source text remains Ink.

Comments and documentary text use Muted.

Language structure such as keywords, types, built-ins, and preprocessors uses
Mineral.

Semantic status colors remain reserved for status:

----
Moss     success
Ochre    warning
Rust     error
----

The port does not assign unrelated chromatic colors to strings, variables,
constants, functions, or other token classes merely to increase color variety.

== Search, diff, and merge

[cols="2,2"]
|===
| Emacs faces | quiet role

| `isearch`, `show-paren-match`
| Ink on Selection

| `lazy-highlight`, `match`, `eglot-highlight-symbol-face`
| Mineral wash

| `diff-added` / `diff-removed` / `diff-changed`
| Moss / Rust / Ochre wash

| `diff-refine-*`
| Ink on the matching emphasis wash

| `ediff-current-diff-A` / `B` / `C` / `Ancestor`
| Rust / Moss / Ochre / Mineral wash

| `ediff-fine-diff-*`
| Ink on the matching emphasis wash

| `smerge-upper` / `smerge-lower` / `smerge-base`
| Mineral wash / Moss wash / Structure

| `trailing-whitespace`
| Rust wash
|===

Line washes and Structure keep every syntax color at its contract minimum,
so those faces set no foreground and source keeps its syntax colors.  The
emphasis tier guarantees only Ink, so refined changes set Ink.

Diff and merge regions keep Emacs's `:extend`, so their backgrounds reach
the window edge.

== Diagnostics

Flymake and Flyspell keep Emacs's wavy underlines, colored Rust for errors
and misspellings, Ochre for warnings and duplicates, and Mineral for notes.
The code beneath keeps its syntax colors.

== ANSI colors

The `ansi-color` faces, which Emacs uses for ANSI-colored output and which
the `term` faces inherit, take quiet's generic terminal palette, so ANSI
output matches quiet's terminal ports.

== Scope

quiet controls color.

It keeps the underlines Emacs's own defaults give links and diagnostics.
It drops Emacs's typographic emphasis, such as bold `error` and `warning`
faces, and does not set:

----
font family
font size
font weight
font slant
overline
box decoration
----

Those remain under the control of Emacs and the user.

== Testing

The test suite verifies that the committed themes match generator output,
that every face uses a known quiet role, and that every face with a
background keeps its text at its contract minimum.

Where Emacs is installed, the suite also loads both themes in a clean
Emacs and checks that every face exists, that every underline quiet sets
is one Emacs's own default draws, and that no wavy underline is dropped.
Set `QUIET_EMACS` to choose a binary.
