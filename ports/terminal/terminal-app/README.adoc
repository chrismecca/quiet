= quiet for Terminal.app

This directory contains the macOS Terminal.app host adapter and generated
quiet reference profiles.

== Profiles

Importable profiles are:

* link:quiet-day.terminal[quiet-day]
* link:quiet-night.terminal[quiet-night]

These files are generated artifacts.

They are not independent palette definitions.

The generation path is:

----
quiet canonical palette
        |
        v
generic ANSI reference mapping
        |
        v
resolved terminal JSON
        |
        v
generate.swift
        |
        v
Terminal.app .terminal profile
----

== Installation

In Finder, double-click either `.terminal` file.

Alternatively:

----
open ports/terminal/terminal-app/quiet-day.terminal
open ports/terminal/terminal-app/quiet-night.terminal
----

Terminal.app imports each file as a profile.

Importing a profile does not automatically make it the default profile.

== Generation

Generate both reference profiles from repository sources with:

----
make terminal-app-profiles
----

Profile generation requires macOS because the serializer uses AppKit.

The generated files are validated with `plutil`.

== Host representation

Terminal.app profiles are XML property lists.

Color values are stored as `NSKeyedArchiver`-encoded `NSColor` objects
embedded as property-list data.

The adapter uses AppKit directly rather than reproducing Cocoa archive
internals in the quiet Go implementation.

quiet color semantics remain outside this adapter.

== Selection

Terminal.app profiles may store an alpha component for Selection.

quiet Selection is an opaque derived display color.

The reference adapter therefore serializes Selection with alpha `1.0`
rather than inheriting Terminal.app's profile-default selection opacity.

== ANSI mapping

The Terminal.app adapter does not define ANSI color semantics.

It consumes the generic reference mapping documented at:

* link:../ansi.adoc[quiet ANSI mapping]

This separation is intentional.

Other terminal hosts should reuse the generic ANSI mapping and implement
only their own host serialization.

== Generated-artifact policy

The `.terminal` files are committed because they are user-consumable port
artifacts.

The semantic sources of truth remain:

----
spec/quiet-day.json
spec/quiet-night.json
internal/port/terminal/
----

Changes to a generated Terminal.app profile should be produced through the
reference pipeline rather than by editing the plist manually.

== Test data

`testdata/sentinel.json` contains deliberately artificial colors used to
exercise Terminal.app serialization.

It is not a quiet palette.
