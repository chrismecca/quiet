= quiet terminal reference port

This directory defines quiet's reference mapping onto the conventional
sixteen-color ANSI terminal model.

The mapping is a port of quiet-core.

It does not extend quiet-core.

== Architecture

The reference-port pipeline is:

----
quiet canonical palette
        |
        v
Go ANSI resolver
        |
        v
resolved terminal JSON
        |
        v
host adapter
----

Host adapters consume the resolved terminal palette rather than
reimplementing quiet-to-ANSI semantics independently.

== Reference mapping

The generic ANSI mapping is documented in:

* link:ansi.adoc[quiet ANSI mapping]

The executable reference implementation lives in:

----
internal/port/terminal/
----

== Host adapters

The first host adapter is:

* link:terminal-app/README.adoc[macOS Terminal.app]

Terminal.app serialization is deliberately separate from the generic ANSI
mapping.

quiet-core defines semantic color roles.

The generic terminal port maps those roles to ANSI.

The Terminal.app adapter only serializes the already-resolved terminal
palette into the host format.

== Test fixture

The script:

----
ports/terminal/ansi-test.sh
----

exercises:

* normal ANSI foregrounds;
* bright ANSI foregrounds;
* normal ANSI backgrounds;
* bright ANSI backgrounds;
* common text attributes;
* semantic approximations;
* selection;
* cursor visibility.

The fixture is intended for host-level evaluation rather than automated
color-science conformance.

== Status

The ANSI mapping is a candidate reference port.

It has been exercised in both quiet-day and quiet-night under macOS
Terminal.app.

The mapping may still change as additional terminal hosts and applications
expose constraints in the ANSI color model.
